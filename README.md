# StreamPick: Game Recommendation Tool

## Problem
StreamPick helps Twitch and YouTube streamers decide which Steam games to play next based on popularity, average playtime, and player ratings.

## What it does
The app answers three questions:
1. Which games have the highest peak concurrent players?
2. Which games have the longest average playtime?
3. Which games have the highest percentage of positive reviews?

It uses these results to recommend games with strong streaming potential.

## How to run it
1. Open StreamPick.ipynb in Google Colab.
2. Make sure steam_games.csv is available in Google Drive.
3. Run the notebook from top to bottom.
4. View the analysis and game recommendations.
